# Money Sync

Shared household finance + shopping list app.

## Stack
- Frontend: React + Vite
- Backend: Express + serverless-http + AWS Lambda
- DB: MongoDB Atlas
- Auth: JWT email/password
- Deploy:
  - Frontend -> Vercel
  - Backend -> AWS Lambda
  - DB -> MongoDB Atlas
